# Session Tracker GUI

This is an application make in Tauri + SvelteKit with the purpose of tracking how long you have played a game for, and accumulating more and more of those play sessions in order to build a picture of your playing habits such as how long you play, when you play and what you play the most. It also serves as a note taking app for the games you play, which is especially useful for long, story based games.

# Basic Tutorial
* Enter the process name of the game into the search bar.
* Select the proces from the search results.
* You will see a stopwatch on the screen once you have selected.
* You can pause the tracker and resume it whenever you like.
* You can stop the tracker by closing the game you are tracking or by stopping it manually via the stop button.
